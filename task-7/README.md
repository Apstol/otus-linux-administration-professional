# Задание 7. Работа с загрузчиком

## Текст задания
- Включить отображение меню Grub.
- Попасть в систему без пароля несколькими способами.
- Установить систему с LVM, после чего переименовать VG.

## Используемое окружение
Arch Linux -> VirtualBox -> Ubuntu 26.04.1 LTS

## Разница между методами получения шелла в процессе загрузки
1. При входе в систему через добавление параметра к ядру `init=/bin/bash` не нужно вводить пароль для рута. Вход происходит в обход systemd, и ядро стартует процесс `/bin/bash` как PID 1. Такой способ дает больше возможностей, но и больше рисков.
2. Вход через Recovery Menu потребует ввести пароль от рута, если он был установлен. Система стартует с минимальным набором сервисов. Такой способ более простой и безопасный.

## Команды для включения отображения Grub меню
```
vim /etc/default/grub
```
Редактируем конфигурацию Grub. Добавляем строки:
```
#GRUB_TIMEOUT_STYLE=hidden 
GRUB_TIMEOUT=10
```
Обновляем конфигурацию и перезагружаемся.
```
update-grub
reboot
```

## Попасть в систему без пароля

### Способ 1. init=/bin/bash
1. Меняем параметры загрузки в Grub меню для ядра Linux. Добавляем `init=/bin/bash` в конце строки, начинающейся с `linux`
2. Чтобы перемонтировать рутовую файловую систему в режиме Read-Write, можно выполнить команду:
```
mount -o remount,rw /
```

### Способ 2. Recovery mode
1. В меню загрузчика выбрать пункт меню с recovery mode в названии.
2. Включить поддержку сети (network), чтобы файловая система перемонтировалась в read/write режим.
3. Выбрать пункт root и ввести пароль, если он был установлен.

## Установить систему с LVM, после чего переименовать VG
1. Переименовать VG
```
vgs
vgrename ubuntu-vg ubuntu-otus
```
2. Отредактировать `/boot/grub/grub.cfg` с заменой старого названия VG на новое. Например `ubuntu--vg` на `ubuntu--otus`.
```
vim /boot/grub/grub.cfg
```
3. Обновить initramfs. Важно, иначе система не сможет инициализироваться, и придется восстанавливаться через live cd, так как в образе initramfs останется ссылка на старое название VG.
```
update-initramfs -u -k all
```
4. Перезагружаемся и проверяем
```
reboot
vgs
```
